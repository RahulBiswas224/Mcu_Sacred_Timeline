# Posters

Drop official movie posters here, named to match each movie's slug — e.g.
`iron-man.jpg`, `avengers-endgame.jpg`, `deadpool-and-wolverine.jpg`.

Each file under `movies/phaseN/*.md` already links to `../../posters/<slug>.jpg`,
so once you add the matching image, it'll render automatically wherever that
movie file is viewed (e.g. on GitHub).

Slugs = the movie title, lowercased, punctuation stripped, spaces to hyphens.
Check the `## Poster` section of any file in `movies/` for the exact filename it expects.
